# Stinky-Notes
Sticky Notes but bad and vibe coded

Always on Top: Keeps your notes visible over other windows.
Click-Through Mode: Interact with windows under the note
Media Support: Images and text.
Grid Snap: Visual grid to align notes.
Global Hotkeys:
Ctrl + Alt + X: Toggle Click-Through mode for all notes.
Ctrl + Alt + L: Toggle the control bar
